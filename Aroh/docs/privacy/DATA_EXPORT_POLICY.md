## 1. Statutory Right to Information & Access

Under **Section 11 of the Digital Personal Data Protection Act, 2023**, a Data Principal has the right to obtain from the Data Fiduciary a summary of personal data which is being processed by the Data Fiduciary and the processing activities undertaken.

AROH empowers users with an automated **"Export My Data"** capability that generates a standardized, machine-readable JSON package of all stored personal data.

## 3. Security & Anti-Exfiltration Safeguards

To ensure that data export cannot be leveraged for unauthorized data exfiltration:
1. **Mandatory Authentication:** Data exports can only be generated by an active, authenticated user session. Unauthenticated requests to `/api/privacy/export` are strictly rejected with HTTP 401.
2. **Scoping:** Export generation queries only documents where `userId === session.userId`. It is mathematically impossible for an export to contain another user's personal data.
3. **No Persistent Export Files:** The export JSON is generated dynamically in memory and streamed directly to the user's browser over TLS 1.3. No static downloadable files are stored on public web servers.
4. **Audit Logging:** Every data export event is recorded in the platform security audit log with timestamp, user identifier, and client IP hash.
